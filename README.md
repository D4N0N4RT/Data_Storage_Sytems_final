# Итоговое задание по дисциплине "Системы обработки данных" (модуль 5)

### 📁 Выполнение работы

1.  **Загрузить исходный датасет**
    Файл `SampleSuperstore.csv` содержит исходный набор данных для работы.

2.  **Генерация бизнес-ключей**
    В исходном датасете отсутствуют бизнес-ключи для основных сущностей бизнес-модели. Для создания хранилища формата Data Vault нам необходимо их создать.
    Для этого был создан скрипт `keys_generation.py`. Данный скрипт генерирует бизнес-ключи, которые необходимы для создания таблиц-хабов.
    *Строки со сгенерированными бизнес-ключами сохраняются в следующем файле:* `SampleSuperstoreWithEntityKeys.csv`

3.  **Описание таблиц Data Vault хранилища**
    **Таблицы-хабы**
    + HUB_CUSTOMERS - хаб-таблица для хранения хэш-ключей потребителей магазина на основе сгенерированных бизнес-ключей 
    + HUB_ORDERS - хаб-таблица для хранения хэш-ключей отправленных заказов магазина на основе сгенерированных бизнес-ключей 
    + HUB_SHIPMENTS - хаб-таблица для хранения хэш-ключей доставок заказов магазина на основе сгенерированных бизнес-ключей 
    + HUB_PRODUCTS - хаб-таблица для хранения хэш-ключей продуктов магазина на основе сгенерированных бизнес-ключей  
    **Таблицы-линки**
    + LINK_CUSTOMER_ORDER - таблица-линк для хранения связи между заказчиком и заказом
    + LINK_ORDER_PRODUCT - таблица-линк для хранения связи между заказом и продуктом
    + LINK_ORDER_SHIPMENT - таблица-линк для хранения связи между заказом и доставкой
    **Таблицы-сателиты**
    + SATELITE_CUSTOMER_SEGMENT - сателит для хранения информации о сегменте потребителя
    + SATELITE_CUSTOMER_LOCATION - сателит для хранения информации о локации потребителя
    + SATELITE_PRODUCT_DETAILS - сателит для хранения информации о продукте
    + SATELITE_ORDER_PRODUCT_DETAILS - сателит для хранения информации о продуктах в заказе

4.  **Создание таблиц в БД**
    В файле `create_tables.sql` написаны SQL запросы для создания таблиц в базе данных под схемой `student56`.

5.  **Загрузка данных В БД**
    Файл `data_import.py` производит преобразование и загрузку данных из файла `SampleSuperstoreWithEntityKeys.csv` в таблицы базы данных
